A local desktop application joining conversation, memory, document retrieval, and tool-based action with operation traceability.

## Presented capabilities

- Hybrid retrieval and consolidated memory across sessions.
- Local workspace for code, OCR, and document creation.
- Acta-specific cognitive ledger and control of personal-file access.

## Scope

The website lists Acta as Preview and describes a Qwen3.5 9B configuration through EIE. A separate local sheet concerns a Gemma 4 26B A4B test variant; its observations do not automatically transfer to the website's configuration.
